 1. TIME-SERIES PREDICTIVE MACHINE LEARNING MODELS
========================================================================================

The forecasting engine predicts the next 14 days (h = 1, 2, ..., 14) for both 
order volume and sales revenue.

----------------------------------------------------------------------------------------
 1.1 MODEL 1: HOLT-WINTERS TRIPLE EXPONENTIAL SMOOTHING (ADDITIVE SEASONALITY)
----------------------------------------------------------------------------------------
Captures baseline sales, linear growth trajectory, and 7-day cyclical weekly seasonality
(period L = 7 days: Monday through Sunday).

* Model Equations:
    Level Update (L_t):
      L_t = alpha * (Y_t / S_{t-L}) + (1 - alpha) * (L_{t-1} + T_{t-1})

    Trend Update (T_t):
      T_t = beta * (L_t - L_{t-1}) + (1 - beta) * T_{t-1}

    Seasonal Index Update (S_t):
      S_t = gamma * (Y_t / L_t) + (1 - gamma) * S_{t-L}

    h-Step Ahead Point Forecast:
      Y_hat_{t+h} = max(0, (L_t + h * T_t) * S_{t - L + (h mod L)})

* Hyperparameter Optimization (Grid Search):
    The engine runs an internal grid search across candidate parameter vectors:
      alpha in {0.10, 0.20, 0.35}  (level responsiveness)
      beta  in {0.05, 0.10}        (trend responsiveness)
      gamma in {0.10, 0.25}        (seasonal responsiveness)

    Objective Function: Minimizes Sum of Squared Errors (SSE) over training history:
      SSE = Sum_{t=1}^n (Y_t - Y_hat_t)^2


----------------------------------------------------------------------------------------
 1.2 MODEL 2: RIDGE AUTOREGRESSIVE MODEL (AR-7 WITH HARMONIC FOURIER TERMS)
----------------------------------------------------------------------------------------
Frames forecasting as a regularized linear regression trained on historical lags, rolling
averages, and trigonometric seasonal harmonics.

* 7-Dimensional Feature Vector for Day t (with weekday index w in {0, ..., 6}):
    X_t = [ 1.0, 
            t / 100.0, 
            sin(2 * pi * w / 7.0), 
            cos(2 * pi * w / 7.0), 
            Y_{t-1}, 
            Y_{t-7}, 
            MA7_t ]^T

    Where:
      - 1.0                  : Bias / Intercept
      - t / 100.0            : Normalized global time drift
      - sin(...), cos(...)   : First harmonic Fourier curve capturing 7-day cyclical oscillations
      - Y_{t-1} (Lag 1)      : Immediate yesterday momentum
      - Y_{t-7} (Lag 7)      : Same-day weekly autoregression (e.g. Saturday to Saturday)
      - MA7_t                : 7-day rolling moving average: (1/7) * Sum_{k=1}^7 Y_{t-k}

* L2 Regularized Optimization (Ridge Penalty):
    Cost Function:
      J(w) = || Y - X*w ||_2^2 + lambda * || w ||_2^2

    Closed-Form Analytical Solution (lambda = 1.0):
      w = (X^T * X + lambda * I)^(-1) * (X^T * Y)

* Forward Autoregressive Prediction:
    Y_hat_{t+h} = max(0, X_{t+h}^T * w)
    (Predicted values feed iteratively into subsequent Lag 1 and MA7 calculations).


----------------------------------------------------------------------------------------
 1.3 MODEL 3: SEASONAL LINEAR TREND MODEL (DE-SEASONALIZED OLS)
----------------------------------------------------------------------------------------
Establishes a baseline growth trajectory decoupled from weekly noise.

* Step 1: Empirical Weekday Index Calculation:
    S_w = weight * (Y_bar_w / Y_bar_global) + (1 - weight) * Prior_w
    where:
      weight = N_w / (N_w + 3.0)  (Bayesian shrinkage weighting)
      Prior  = [0.85, 0.88, 0.92, 0.95, 1.15, 1.35, 1.25] (Mon -> Sun cafe industry prior)

* Step 2: De-seasonalization:
    Y_tilde_t = Y_t / S_{w(t)}

* Step 3: Ordinary Least Squares (OLS) Linear Fit:
    Slope (m):
      m = ( n * Sum(t * Y_tilde_t) - Sum(t) * Sum(Y_tilde_t) ) / ( n * Sum(t^2) - (Sum(t))^2 )

    Intercept (b):
      b = ( Sum(Y_tilde_t) - m * Sum(t) ) / n

* Step 4: Re-seasonalized Point Prediction:
    Y_hat_{t+h} = max(0, (b + m * (t + h)) * S_{w(t+h)})


----------------------------------------------------------------------------------------
 1.4 DYNAMIC ENSEMBLE: INVERSE-RMSE MODEL BLENDING
----------------------------------------------------------------------------------------
Rather than relying on a single algorithm, the engine backtests each candidate model
on the historical series and computes its Root Mean Squared Error (RMSE):

    RMSE_m = sqrt( (1 / n) * Sum_{t=1}^n (Y_t - Y_hat_{m, t})^2 )

* Dynamic Inverse-Error Weight Calculation:
    w_m = ( 1 / max(0.01, RMSE_m) ) / Sum_{k in {HW, Ridge, SL}} ( 1 / max(0.01, RMSE_k) )

* Final Blended Ensemble Forecast:
    Y_hat_ensemble = w_HW * Y_hat_HW + w_Ridge * Y_hat_Ridge + w_SL * Y_hat_SL


----------------------------------------------------------------------------------------
 1.5 FORECAST ACCURACY METRIC: WEIGHTED ABSOLUTE PERCENTAGE ERROR (WAPE)
----------------------------------------------------------------------------------------
Standard MAPE divides by actual daily sales (|Y - Y_hat| / Y). On quiet days with 0 or 1
orders, MAPE explodes toward infinity. The engine utilizes WAPE (Weighted Absolute
Percentage Error):

    WAPE = Sum_{t=1}^n | Y_t - Y_hat_t | / Sum_{t=1}^n Y_t

* Reported System Accuracy:
    Model Accuracy (%) = max(0, 1.0 - WAPE) * 100%


----------------------------------------------------------------------------------------
 1.6 DYNAMIC UNCERTAINTY BANDS: P10 DOWNSIDE & P90 UPSIDE (CONFIDENCE ENVELOPES)
----------------------------------------------------------------------------------------
Quantifies prediction risk using residual standard deviation (sigma_res = RMSE_ensemble).
Uncertainty scales with the forecast horizon step h in {1, ..., 14}:

* For Order Count:
    Margin_orders(h) = 1.28 * max( sigma_res, sqrt(max(1.0, Y_hat) * 1.5) ) * sqrt( 1.0 + 0.03 * h )

* For Revenue:
    Margin_revenue(h) = 1.28 * max( sigma_res, Y_hat * 0.16 + 50.0 ) * sqrt( 1.0 + 0.04 * h )

* Confidence Envelopes (80% confidence interval, z = 1.28):
    P10 (Pessimistic Floor / "Rainy Day" Scenario):
      P10 = max(0, Y_hat - Margin(h))

    P90 (Optimistic Ceiling / "Rush Surge" Scenario):
      P90 = Y_hat + Margin(h)


----------------------------------------------------------------------------------------
 1.7 STRUCTURAL REVENUE TRANSFORMATION
----------------------------------------------------------------------------------------
Revenue is coupled with expected volume and historical day-of-week Average Order Value:
    Structural_Rev(h) = Y_hat_orders(h) * AOV_{w(h)}

The final revenue forecast blends the statistical ML series with structural economics:
    Y_hat_final_rev = 0.65 * Y_hat_ensemble_rev + 0.35 * Structural_Rev

 2. OPERATIONAL & QUEUE SIMULATION MODELS
========================================================================================

----------------------------------------------------------------------------------------
 2.1 QUEUEING FLOW SIMULATION (HOURLY BOTTLENECK ANALYSIS)
----------------------------------------------------------------------------------------
Models customer arrivals and kitchen throughput for each hour h in {0, ..., 23}:

* Arrival Rate (lambda_h):
    lambda_h = Mean orders arriving during hour h on that specific weekday.

* Barista Preparation Capacity (mu):
    mu = 12 orders / barista / hour (industry cafe service benchmark).

* Active Staffing (c_h):
    c_h = max( 1, ceil( lambda_h / mu ) )

* Total Station Service Capacity (C_h):
    C_h = c_h * mu

* System Utilization (Traffic Intensity rho):
    rho = lambda_h / C_h


----------------------------------------------------------------------------------------
 2.2 CUSTOMER QUEUE WAIT-TIME FORMULATION
----------------------------------------------------------------------------------------
Projects expected customer queue wait time W_q (in minutes) based on traffic intensity rho:

    W_q(rho) =
      |  0.0 minutes                             , if lambda_h = 0  (Closed/Quiet)
      |  2.0 + 3.0 * rho                         , if 0.00 < rho < 0.60  (Optimal)
      |  4.0 + 12.0 * (rho - 0.60)               , if 0.60 <= rho < 0.85  (Steady)
      |  8.0 + 40.0 * (rho - 0.85)               , if 0.85 <= rho < 1.00  (Peak Rush)
      |  15.0 + 30.0 * (rho - 1.00)              , if rho >= 1.00  (Congested Bottleneck)

 3. FINANCIAL & CASH FLOW METRICS
========================================================================================

----------------------------------------------------------------------------------------
 3.1 AVERAGE ORDER VALUE (AOV)
----------------------------------------------------------------------------------------
    AOV = ( Total Valid Gross Sales ) / ( Total Completed Orders )
    Where valid orders are strictly: status != OrderStatus.cancelled.

----------------------------------------------------------------------------------------
 3.2 14-DAY FINANCIAL RUN RATE
----------------------------------------------------------------------------------------
    Daily Run Rate = ( Sum_{h=1}^{14} Y_hat_revenue(h) ) / 14

----------------------------------------------------------------------------------------
 3.3 WEEKEND SURGE RATE MULTIPLIER
----------------------------------------------------------------------------------------
Measures customer demand acceleration on Saturday and Sunday vs. standard weekdays:

    Rev_weekend_avg = Sum(Weekend Revenue) / Total Weekend Days
    Rev_weekday_avg = Sum(Weekday Revenue) / Total Weekday Days

    Weekend Surge (%) = ( (Rev_weekend_avg - Rev_weekday_avg) / Rev_weekday_avg ) * 100%

----------------------------------------------------------------------------------------
 3.4 6-MONTH ROLLING FINANCIAL PROJECTION
----------------------------------------------------------------------------------------
Tracks 5 historical months + current active month + 1 future month:
    Current Month Total = Actual Revenue to Date + Projected Revenue for Remaining Days

 4. PRESCRIPTIVE & INVENTORY OPTIMIZATION
========================================================================================

----------------------------------------------------------------------------------------
 4.1 DAILY CONSUMPTION VELOCITY & MOMENTUM GROWTH
----------------------------------------------------------------------------------------
For each menu product p:

* Average Daily Consumption Rate (d_bar):
    d_bar = Total Units Sold / Training Days

* Momentum Growth Ratio (g):
    Compares sales in the first half of the window (U_first) vs. the second half (U_second):
    g = U_second / max( 1.0, U_first )

----------------------------------------------------------------------------------------
 4.2 7-DAY DEMAND FORECAST & SAFETY STOCK FORMULATION
----------------------------------------------------------------------------------------
* 7-Day Forward Demand Projection:
    D_7 = d_bar * g * 7 days

* Recommended Target Stock Level (with 1.30 safety buffer):
    Target Stock = ceil( D_7 * 1.30 )

* Reorder Quantity to Purchase:
    Reorder Units = max( 0, Target Stock - Current Stock )

* Urgency Thresholds:
    - CRITICAL  : Current Stock == 0 or Days Left < 1.0 day
    - LOW STOCK : Days Left < 3.0 days
    - HEALTHY   : Days Left >= 3.0 days

----------------------------------------------------------------------------------------
 4.3 STOCKOUT TIMELINE ESTIMATION (DAYS LEFT)
----------------------------------------------------------------------------------------
    Days Left = Current Stock / ( d_bar * g )
    Stockout Date = Today + floor( Days Left )

 5. MENU ENGINEERING & MARKETING ANALYTICS
========================================================================================

----------------------------------------------------------------------------------------
 5.1 BOSTON CONSULTING GROUP (BCG) MENU MATRIX THRESHOLDS
----------------------------------------------------------------------------------------
Evaluates menu profitability and popularity thresholds:

* Popularity Threshold (theta_pop):
    theta_pop = 0.70 * ( Total Units Sold / Count of Unique Menu Items )

* Profitability / Price Threshold (theta_price):
    theta_price = Total Product Revenue / Total Units Sold

* Classification Matrix:
    1. STARS      : Units Sold >= theta_pop  AND  Avg Price >= theta_price
                    (High Volume, High Profit -> Protect quality & recipe consistency)
    2. PLOWHORSES : Units Sold >= theta_pop  AND  Avg Price < theta_price
                    (High Volume, Low Profit -> Popular staples; increase price by ₱5-₱10)
    3. PUZZLES    : Units Sold < theta_pop   AND  Avg Price >= theta_price
                    (Low Volume, High Profit -> Gourmet items; boost social promotions)
    4. DOGS       : Units Sold < theta_pop   AND  Avg Price < theta_price
                    (Low Volume, Low Profit -> Low demand; consider retiring or replacing)

----------------------------------------------------------------------------------------
 5.2 MARKET BASKET ANALYSIS (SMART BUNDLE CO-OCCURRENCE)
----------------------------------------------------------------------------------------
Scans multi-item receipts to identify beverage-pastry co-occurrence:

* Pair Co-Occurrence Frequency:
    PairCount(A, B) = Count of orders where both Item A and Item B are present.

* Bundle Share:
    Share(A, B) = PairCount(A, B) / Total Multi-Item Orders

* Recommended Bundle Combo Pricing (10% Discount):
    Regular Price = Price_A + Price_B
    Bundle Price  = Regular Price * (1.0 - 0.10)

 6. CUSTOMER RFM & RETENTION INTELLIGENCE
========================================================================================

----------------------------------------------------------------------------------------
 6.1 RECENCY, FREQUENCY, MONETARY (RFM) SEGMENTATION MATRIX
----------------------------------------------------------------------------------------
Categorizes customers into cohorts based on:
  - Recency (R)  : Days elapsed since customer's last order ( Today - LastOrderDate )
  - Frequency (F): Total count of lifetime completed orders
  - Monetary (M) : Total cumulative pesos spent

* Segmentation Rules:
    1. Champions (VIP Regulars) : Frequency >= 4 orders  AND  Recency <= 7 days
    2. Loyal Patrons            : Frequency >= 3 orders  AND  Recency <= 14 days
    3. Promising High-Value     : Frequency <= 2 orders  AND  Recency <= 10 days  AND Spend >= ₱300
    4. At-Risk (Churn Warning)  : Frequency >= 2 orders  AND  14 days < Recency <= 30 days
    5. Occasional / Inactive    : Recency > 30 days or Single-visit walk-ins

----------------------------------------------------------------------------------------
 6.2 STORE CUSTOMER RETENTION RATE FORMULA
----------------------------------------------------------------------------------------
    Retention Rate (%) = ( Repeat Customers [Frequency >= 2] / Total Unique Customers ) * 100%
