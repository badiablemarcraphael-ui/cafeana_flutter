=====================================================================
                 CAFEANA PROJECT GUIDE - WHAT IS WHAT
=====================================================================

Cafeana is a full cafe ordering and management system made of 3 parts:

  1. A Flutter app (mobile + web)  -> customers order, staff manage the cafe
  2. Firebase (cloud backend)      -> login, database, push notifications
  3. ESP32 kitchen terminal        -> small device in the kitchen with an
                                      OLED screen + buzzer that alerts staff
                                      when a new order arrives

HOW AN ORDER FLOWS
  Customer places order (app)
     -> saved in Firestore "orders" collection with status "queued"
     -> Staff dashboard sees it instantly + ESP32 buzzes in the kitchen
     -> Staff taps "Start Preparing" -> status "preparing"
     -> Staff taps "Mark as Ready"   -> status "ready" (customer is notified)
     -> Staff taps "Complete"        -> status "completed" (goes to analytics)

USER ROLES (stored in Firestore users/{uid}.role)
  customer -> customer app (/customer/...)
  owner    -> full staff dashboard (every page)
  cashier  -> staff dashboard (Home, Queue, Feed, Menu, Inventory)
  kitchen  -> order queue only (no side navigation)

=====================================================================
 FIRESTORE DATABASE COLLECTIONS (from firestore.rules)
=====================================================================
users          user profiles + roles
products       menu items
ingredients    inventory stock
addOns         extra add-ons (e.g. extra shot)
orders         all orders
counters       running order number (#1001, #1002, ...)
feedback       customer ratings (1 per order)
promotions     discount codes
inventoryLog   stock change history
activityLogs   staff action history
deviceStatus   ESP32 online/offline heartbeat


=====================================================================
 COMMON COMMANDS
=====================================================================
cd mobile_web_app
flutter pub get                         install packages
flutter run -d chrome                   run as website
flutter run -d web-server --web-port 8080   run local web server
flutter build web                       build website for hosting
firebase deploy --only hosting          upload website to Firebase
firebase deploy --only firestore:rules  upload database rules
flutter analyze                         check code for problems
flutter test                            run automated tests

cd mobile_web_app/functions
node dispatcher.js                      free push-notification sender

cd firmware
pio run --target upload                 flash code to the ESP32
